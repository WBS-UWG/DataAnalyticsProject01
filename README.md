# 1. Problem statements
The datasource I decided to use is the GCAT (General Catalog of Artificial Space Objects) dataset, which contains information about various artificial satellites and space objects.
The link to the dataset is: [GCAT Dataset](https://planet4589.org/space/gcat/root.html)

## Dataset overview :
- size => contains +31K records of artificial space objects.
- columns => includes information such as object name, type, launch date, and orbital parameters.
- Recent data => The last update of the dataset was on 2026 sep 8
